Turn any photo into GTA 6-poster-style cover art. Neon Vice Cover Studio is an offline static web app: pick a layout (6 options), a grade (5 Vice City sunset/neon grades) and an export size (1080x1080, 1080x1350, 1920x1080), load up to 4 photos, drag to pan and zoom per panel, edit the title and subtitle, then export a PNG.

Run it: `node serve.ts` and open http://localhost:8080 — or open `app/index.html` directly. Build the dossier with `MAKEFUN_OUTPUT_DIR=out node main.ts`.

Made for the [Make GTA 6 Cover Art bounty](https://make.fun/bounty/gta6-cover-art-01) on [make.fun](https://make.fun).
